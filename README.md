# からまつ苑 利用料金シミュレーター

特別養護老人ホームからまつ苑(社会福祉法人治栄会)の月額利用料金を、スマートフォンから概算シミュレーションできるWebアプリ(PWA)です。

**このアプリは概算シミュレーションを行うものであり、実際の請求額を確定するものではありません。**

**公開URL: https://hangeishi-rgb.github.io/karamatsuen-fee-simulator/**
(iPhoneのSafariでこのURLを開き、共有ボタン→「ホーム画面に追加」でアプリのように使えます)

---

## 1. アプリ概要

- 要介護度・負担割合・居室タイプ・利用日数・負担限度額段階・高額介護サービス費区分を選択すると、月額利用料金の概算を計算します。
- 結果画面の「印刷する(PDFで保存)」ボタンから、ブラウザ標準の印刷機能(印刷ダイアログの「PDFに保存」)でご利用条件と計算結果を書類として出力できます(家族説明用など)。入力欄やボタンは印刷されず、結果部分だけがきれいに出力されます。
- 対象データは令和8年8月1日からまつ苑料金表、および大阪市公式の高額介護サービス費情報です。
- Node.js等のビルドツールを使わない、素のHTML/CSS/JavaScript(ES Modules)で実装しています。
- ブラウザだけで完結し、外部サーバーへの通信は行いません(入力された金額・条件も送信されません)。

## 2. 起動方法・開発環境

Node.jsは不要です。ローカルの静的Webサーバーで `index.html` を配信するだけで動作します。

fetch() で `data/*.json` を読み込むため、`file://` で直接開くとブラウザのセキュリティ制限で読み込みに失敗する場合があります。必ず簡易HTTPサーバー経由で開いてください。

例(Windows PowerShellで手軽に確認する場合):

```powershell
# プロジェクトフォルダで実行(Pythonが使える場合)
python -m http.server 8080

# その後ブラウザで http://localhost:8080/ を開く
```

Pythonが無い場合は、VSCodeの「Live Server」拡張機能や、他の任意の静的サーバーでも構いません。

## 3. 本番公開・iPhoneへの追加方法

1. `index.html` を含むこのフォルダ一式を、HTTPS対応の任意のWebホスティング(GitHub Pages、Netlifyなど)にアップロードします。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン(□に↑の付いたアイコン)をタップし、「ホーム画面に追加」を選択します。
4. ホーム画面に「からまつ苑料金計算」というアイコンが追加され、アプリのように起動できます(standalone表示・オフライン計算対応)。

※ PWAのService Worker・ホーム画面追加はHTTPS環境(またはlocalhost)でのみ正しく動作します。

### 料金改定・制度改定時の修正方法

本アプリは、料金改定のたびにプログラムのコードを直す必要がないように設計しています。新しい日付のJSONを追加するだけで、アプリが自動的に「今日時点で有効な最新の料金」を選んで使うようになります。

- **からまつ苑の料金改定**(基本単位・加算単位・処遇改善加算率・地域区分単価・食費居住費が変わった場合):
  1. `data/karamatsu/` に新しい日付のJSON(例: `2027-04-01.json`)を追加する(既存ファイルは変更せず残す。過去分の検証や切り戻しがしやすくなるため)。
  2. `data/karamatsu/versions.json` の `versions` 配列に、その新しい日付("2027-04-01")を追加する。
  3. これだけで、`js/app.js` や計算ロジックのコードは一切変更せずに反映されます(`js/calculation/versionSelect.js` が、実行時点の日付に対して有効な最新バージョンを自動選択します)。
- **大阪市 高額介護サービス費の上限額改定**: 同様に `data/osaka/high-cost-care/` に新しい日付のJSONを追加し、`data/osaka/high-cost-care/versions.json` にその日付を追加してください。
- 料金・単価を計算ロジック(`js/calculation/*.js`)に直接書き込むことは絶対にしないでください。すべてJSONマスタ側で管理する設計です。
- ファイルを追加・変更したら、`service-worker.js` の `CACHE_NAME` のバージョン文字列を上げてください(上げないと、既にホーム画面に追加した利用者の端末に更新が反映されないことがあります)。新しいJSONファイルは `APP_SHELL_FILES` にも追加しておくと、オフライン時の初回読み込みにも対応できます。
- 変更後は `tests/test.html` で全件パスすることを確認してから、`git add` → `git commit` → `git push` でGitHub Pagesに反映してください。

## 5. 計算式(からまつ苑公式料金表に明記された算定方法)

介護サービス費の計算は以下の手順で行い、**すべて切り捨て(円未満・単位未満とも)** で処理します。この端数処理ルールは、料金表に掲載された30日利用時の金額(70パターン)を全て逆算し、誤差0円で一致することを確認した上で確定させています(推測ではありません)。

```
Ⅰ = (基本サービス単位 + 通常加算単位) × 利用日数
Ⅱ = 月額加算単位(利用日数を掛けない、定額)
Ⅲ = floor((Ⅰ + Ⅱ) × 処遇改善加算率17.6%)          … 単位未満切り捨て
Ⅳ = floor((Ⅰ + Ⅱ + Ⅲ) × 地域区分単価10.72円)        … 円未満切り捨て(総費用額)
介護サービス自己負担額 = floor(Ⅳ × 負担割合)          … 円未満切り捨て
```

食費・居住費は、居室タイプ(従来型個室/多床室)と負担限度額段階(第1〜4段階)の組み合わせから1日あたりの金額を料金表マスタで引き、利用日数を掛けて算出します(端数処理不要)。

高額介護サービス費は、からまつ苑の介護サービス自己負担額と、他の介護保険サービスの自己負担額(入力値)の合計を、選択された区分の世帯単位上限額と比較し、超過分を軽減額として按分計算します(`js/calculation/highCostCare.js` 参照)。

高額介護サービス費区分で「生活保護受給等」を選択した場合、負担限度額は自動的に「第1段階」に連動し、介護サービス自己負担・食費・居住費のすべてを、生活保護の介護扶助と介護保険の高額介護サービス費の組み合わせにより本人負担0円として表示します(内訳・第1段階相当額は参考情報として表示)。この判定は `data/osaka/high-cost-care/2026-08-01.json` の `residentBurdenWaived` フラグに基づきます。詳細は「6. 確認が必要な計算ルール」の7番を参照してください。

## 6. 確認が必要な計算ルール・実装済みの前提条件

以下は開発時にユーザーへ確認・合意した仕様上の前提です。制度や運用が変わった場合は見直してください。

1. **高額介護サービス費の区分(STEP6)は任意選択**です。「選択しない(わからない)」を選ぶか、何も選ばずに計算した場合、高額介護サービス費による軽減額の計算自体を行わず、介護サービス自己負担額をそのまま合算します(結果画面にはその旨を表示します)。
2. **高額介護サービス費の個人単位上限**: 「非課税世帯・一定所得以下」区分には世帯単位24,600円と個人単位15,000円の両方が定められていますが、本アプリでは**世帯単位の上限額のみ**を計算に使用し、個人単位の上限額は参考情報として保持するに留めています(`data/osaka/high-cost-care/2026-08-01.json` の `individualLimit` フィールド)。個人単位の限度額まで厳密に計算したい場合は仕様変更が必要です。
3. **個別加算(初期加算・外泊時加算・看取り介護加算)はVer.1では未実装**です。料金表に存在するデータ(単位数・算定条件)は `data/karamatsu/2026-08-01.json` の `individualAdditions` に保持していますが、計算には反映していません(常に0として扱われます)。該当する利用者の場合、実際の請求額は本アプリの概算より高くなる場合があります。
4. **高額介護サービス費の按分方法**: からまつ苑分と他サービス分の自己負担額の比率で軽減額を按分する実装としています(世帯合算の一般的な考え方に基づく簡易計算)。公式な按分方法が別途定められている場合は要確認です。
5. **月額加算(1か月につき算定する加算)は、利用日数に関わらず定額で1回のみ加算**しています(月途中の入退所でも按分しません)。料金表の30日料金例だけでは月途中利用時の挙動を検証できないため、この点は料金表の注記(「月単位加算は日数を掛けない」という開発時の仕様合意)に基づく実装です。
6. **「他の介護保険サービスの利用」「その他費用」の入力欄はUIから削除済み**です(ユーザー指示により2026-09-14に削除)。計算ロジック(`js/calculation/highCostCare.js`・`js/calculation/total.js`)には引き続きパラメータとして残っており、常に0円として計算されます。将来これらの入力を復活させたい場合は、計算ロジックの変更は不要で、UI(`index.html`・`js/app.js`)に入力欄を追加するだけで対応できます。
7. **生活保護受給等の場合、介護サービス自己負担・食費・居住費のすべてを本人負担0円として扱う**: からまつ苑の料金表・大阪市の高額介護サービス費ページのどちらにも直接の記載はなく、生活保護法上の介護扶助に関する制度理解に基づく実装です(2026-09-14にユーザーへ確認のうえ反映)。
   - **給付の優先順位は「(1)介護保険 → (2)生活保護」**です(生活保護法の他法優先の原則)。介護サービス自己負担額(1〜3割相当分)については、まず介護保険の「高額介護サービス費」が上限額(15,000円)を超えた分を給付し、**残る上限額までの部分を生活保護の「介護扶助」が全額支給**します。どちらも公費であり本人の実費負担は生じないため、`js/calculation/total.js` では「適用前」「上限額(15,000円)」「高額介護サービス費支給額」を内訳の参考情報として保持しつつ、最終的な本人負担額(`finalCareServiceCopay`)は0円にしています。
   - **画面に表示する介護扶助の金額は、上限額(15,000円)そのものではなく `highCostCare.amountAfterLimit`(= min(自己負担相当額, 上限額))を使用**しています。月途中の入退所や短期利用で自己負担相当額が15,000円を下回る場合に、介護扶助の支給額を実額より大きく表示してしまうのを防ぐためです。この場合はバナーの文面も「全額が介護扶助から支給されます」に切り替わります(`js/app.js`)。
   - 食費・居住費も同じ順序です。基準費用額との差額を介護保険の**補足給付(特定入所者介護サービス費)**が負担し、**負担限度額認定(第1段階)適用後の自己負担分を介護扶助が全額支給**するため0円としています。
   - この判定は `data/osaka/high-cost-care/2026-08-01.json` の「生活保護受給等」区分に設定した `residentBurdenWaived` フラグに基づきます。
   - **年齢による制度上の違い(本アプリの計算結果には影響しません)**: 65歳以上(第1号被保険者)は上記の通り介護保険と生活保護の間で給付調整が行われます。40〜64歳で医療保険(国保等)から外れている場合(第2号被保険者としての資格がない場合)は、介護保険からの給付調整自体が発生せず、全額が生活保護の介護扶助から直接支給されます(「みなし2号」)。いずれの場合も本人負担は0円という結果は変わりません。
   - **施設事務での実務上の注意(アプリの計算結果とは別に、運用上ご留意ください)**: 高額介護サービス費は通常、被保険者本人の口座に振り込まれますが、生活保護受給者の自己負担分は介護扶助(公費)から支出されているため、本人へ振り込まれた高額介護サービス費は本人の収入にはできません。福祉事務所と協議のうえ代理受領の手続きを取るか、入金された場合は福祉事務所への返納(保護費の調整)が必要です。また、施設側の請求事務では、介護保険証の負担区分(第1段階)と福祉事務所発行の介護扶助券の記載内容を照合してください。
   - 個別の状況(資産保有等)によっては実態と異なる場合があります。

## 7. テスト方法

Node.js不使用のため、ブラウザ上で動作する簡易テストランナーを用意しています。

1. 「起動.bat」をダブルクリックするか、任意のローカルサーバーでこのフォルダを配信します(上記「起動方法」参照)。
2. ブラウザで `http://localhost:8791/tests/test.html` を開きます。
3. `TOTAL: 104  PASS: 104  FAIL: 0` のように、全件パスすることを確認してください。

テスト内容:
- 料金表に掲載された30日利用時の金額(要介護1〜5 × 負担限度額第1〜4段階 × 従来型個室/多床室の1割負担、および要介護1〜5 × 第4段階 × 個室/多床室の2割・3割負担、計70パターン)を、計算式から算出した結果と一字一句突き合わせています。
- 高額介護サービス費の区分を選択しなかった場合に、軽減額の計算をスキップして自己負担額をそのまま合算すること。
- 高額介護サービス費の按分計算(軽減なしケース・軽減ありケース・他サービスありケース)。
- 月途中利用(利用日数が30日以外)の計算。

## 8. 注意事項

- 本アプリの結果は概算です。実際の請求額とは、算定された加算、利用日数、端数処理、制度適用状況、その他費用等により異なる場合があります。
- 高額介護サービス費の適用には制度上の要件があります。このシミュレーションは実際の支給額を確定するものではありません。
- 個人情報(氏名・生年月日・住所・介護保険番号等)は入力・保存しません。
